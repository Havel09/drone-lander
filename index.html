Drone Lander

Le jeu du drone piloté par les capteurs de votre téléphone : inclinez-le pour vous déplacer et pour la poussée.

Version 1.0.0 Android 7.0+ 4,3 Mo Gratuit
⬇️ Télécharger l'APK (Android)

…

  1. Téléchargez l'APK avec le bouton orange.
  2. Ouvrez le fichier téléchargé pour lancer l'installation.
  3. Si demandé, autorisez « Sources inconnues » pour votre navigateur.
  4. Jouez ! L'app se pilote à l'inclinaison (bouton « Démarrer » au premier lancement).
